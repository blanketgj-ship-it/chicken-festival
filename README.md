# Chicken Festival

An illustrated invitation for November 1, 2026, with an interactive envelope, animated chickens, and a four-dish menu.

## Local preview

Run `node server.cjs`, then open http://localhost:3000.

The website uses plain HTML, CSS, and JavaScript. No installation or build is required.

## Publishing

GitHub Pages serves the root of the `main` branch. Changes pushed to `main` are published automatically.
